# Simple Profit Analysis using Excel

## 📊 Project Overview

This project performs a simple profit analysis using Excel. The main objective is to compare total profit across different product categories and understand basic profitability.

## 🎯 Objective

- Calculate total sales by product category
- Calculate total profit by product category
- Compare average profit
- Analyze profit margin
- Create a chart for category-wise profit comparison

## 🛠️ Tools Used

- Microsoft Excel
- CSV
- GitHub

## 📁 Project Files

- `Simple_Profit_Analysis.xlsx` – Excel workbook containing raw data, profit summary and chart
- `profit_summary.csv` – Category-wise profit summary

## 📈 Analysis

The analysis groups the data by product category and compares:

- Total Sales
- Total Profit
- Average Profit
- Profit Margin

## 💡 Key Finding

Based on the sample dataset, the Technology category has the highest total profit.

## 📊 Visualization

A bar chart is included in the Excel workbook to compare total profit across product categories.

Through this project, I practiced:

- Data grouping
- SUM and AVERAGE calculations
- Profit comparison
- Basic data analysis
